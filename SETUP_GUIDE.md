# SPENDY — Android Studio Setup & Run Guide

## Project: SPENDY
**Stack**: React Native + Expo bare workflow | TypeScript | SQLite | Kotlin native modules

---

## 1. Android Studio Setup (One-Time)

After Android Studio finishes installing:

1. **Open Android Studio**, go to:
   `File → Settings → Appearance & Behavior → System Settings → Android SDK`

2. Install **SDK Platform API 35** (or 33+) and these SDK Tools:
   - Android SDK Build-Tools
   - Android Emulator
   - Android SDK Platform-Tools
   - Intel x86 Emulator Accelerator (HAXM) ← critical for emulator speed

3. **Set ANDROID_HOME** environment variable:
   - Value: `C:\Users\Yash\AppData\Local\Android\Sdk`
   - Add `%ANDROID_HOME%\platform-tools` to your PATH

4. Verify: open a new terminal and run:
   ```
   adb devices
   ```

---

## 2. Run the App on Your Phone (Recommended over emulator for SMS/notification testing)

### Step A — Enable Developer Mode on your phone:
1. Go to **Settings → About Phone**
2. Tap **Build Number** 7 times → "Developer mode enabled"
3. Go to **Settings → Developer Options**
4. Enable **USB Debugging**

### Step B — Connect + verify:
```powershell
adb devices
# Should show:  XXXXXXXXXXXX device
```

### Step C — Run Expo prebuild (generates the android/ folder):
```powershell
cd D:\moneyproj
npx expo prebuild --platform android
```

### Step D — Build + install + run:
```powershell
npx expo run:android
```

This compiles Kotlin, bundles JS, installs the APK on your phone, and starts the Metro bundler.
After the first build succeeds, **JS changes hot-reload instantly** — no need to re-run this command.

---

## 3. After Prebuild — Add Kotlin Native Modules

After `npx expo prebuild` generates the `android/` folder:

1. Open the `android/` folder in Android Studio:
   `File → Open → select D:\moneyproj\android`

2. Create these Kotlin files under:
   `android/app/src/main/java/com/spendy/app/`

   See `src/native/KotlinModules.ts` for the full source code of:
   - `SmsReceiver.kt`
   - `SmsParseWorker.kt`
   - `BankNotificationListener.kt`
   - `NotificationParseWorker.kt`

3. Add the permissions + service/receiver declarations to:
   `android/app/src/main/AndroidManifest.xml`
   (See the AndroidManifest section in `src/native/KotlinModules.ts`)

4. Add WorkManager dependency to `android/app/build.gradle`:
   ```kotlin
   implementation "androidx.work:work-runtime-ktx:2.9.0"
   ```

5. Re-run: `npx expo run:android`

---

## 4. Permissions to Grant on First Launch

After installing on your phone, you'll need to manually enable:

1. **Notification Listener**:
   Settings → Notifications → Notification Access → SPENDY → Enable

2. **Battery Optimization**:
   Settings → Apps → SPENDY → Battery → Unrestricted
   (Critical for Xiaomi/OPPO/Vivo phones with aggressive battery management)

3. **SMS Permission**:
   Will be requested automatically on first launch.

---

## 5. Dev Workflow After First Build

| What changed | What to run |
|---|---|
| JS/React/TypeScript only | Nothing — hot reload handles it |
| New npm package (JS only) | `npm install <pkg>` → reload |
| New native dependency | `npx expo run:android` (full rebuild) |
| Kotlin code changed | `npx expo run:android` (full rebuild) |
| Share with friends (no Play Store) | `eas build --platform android --profile preview` |

---

## 6. EAS Build (Shareable APK)

Install EAS CLI:
```powershell
npm install -g eas-cli
eas login
eas build --platform android --profile preview
```

This produces a QR code / download link for an installable APK anyone can sideload.
